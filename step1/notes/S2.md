# S2 — adapters and training code for the other architectures (2026-11-06)

**Files.**
- `scripts/s1_arch.py`: adapters and `score_arch(run_dir, arena, scales)`.
- `scripts/s1_train_baseline.py`: copy of the reproduction's training script. Changed lines are marked `S1:`.
- `scripts/test_s1.py`: tests (vi)–(ix) added. All 22 tests pass in 238 s.
- `scripts/s2_probe.py` writes the key `S2` in `results/s1_probe.json`.

**Pairing.** Each model reads command row r when it predicts state row r. That is `lyap.rollout_map`'s pairing (offset 1), so nothing differs from the GRU.

**Step-map state.**
- MLP and Transformer: the 32-row window of states and joint commands (n = 1,824).
- RSSM: the GRU latent and the last prediction (n = 557). The categorical latent is the prior's argmax, so its derivative is zero (DECISIONS S2-1).

**Tests.**
- (vi): all 26 runs held out episodes 1 and 8, so none is left out. One-step predictions equal the reproduction's code exactly (difference 0).
- (vii): JVP against finite differences agrees within 4e-9 for all 7 specs. On a GRU, the generic code reproduces `lyap.rollout_map`, `evalh` and `lyap.lyapunov` exactly.
- (viii): values are finite and shapes as expected. Rollouts equal the reproduction's `rollout` exactly. The random MLP diverges after about 190 steps.
- (ix): training losses equal the stored curves bit for bit at 2 threads. In a check, 1 or 4 threads drifted by about 1e-5 within 50 iterations.

**Probe** (2 threads):
- scoring all 38 runs takes 6.7 minutes in total;
- training seconds per iteration: MLP 0.06–0.09, Transformer 1.0, RSSM 2.1–2.6;
- two RSSM runs side by side, at 1 thread each, take 4.45 s per iteration each;
- the 12 new runs take 9.6 h one at a time, or 8.1 h two at a time.

**For S3** (DECISIONS S2-1…6): register the RSSM map and the divergence handling. Train one run at a time at 2 threads.

No trained baseline was scored. No model was trained beyond 50 iterations, and those runs went to `.cache/` only.
