# S1 — closed-loop measurement code (2026-11-06)

**Files.**
- `scripts/s1_policy.py`: actor, observation, velocity command, reward.
- `scripts/s1_rollout.py`: `score_gru(model, arena, scales, items, p=1, actor, policy)`.
- `scripts/test_s1.py`: 13 checks, all pass, 15 s, saves nothing.
- `scripts/s1_probe.py` writes `results/s1_probe.json`.

**Alignment.** Fed state row r and command row r, the actor's output is command row r+1. In `lyap.rollout_map` (offset 1), that is the command that moves row r to r+1. Test (iv) confirms this: a "policy" that replays the recording reproduces the open-loop rollout exactly in float64 and gives λ1_cl = λ1.

**Test results.**
- (i) R² at offsets −1 and 0: 0.485982 and 0.391141, the same as task1c. Observation identical to the authors'.
- (ii) λ1 on a linear map: 4.99998 (true value 5). λ1_cl with u = Kx: 5.00034 (A+BK true value 5). It equals the exact finite-time value to 1e-9.
- (iii) A_s0 and B_s0, recorded commands only: λ1 rel diff ≤ 4e-12, r̄J ≤ 3.2e-5.
- (v) Constructed blow-ups: right step, checks +inf, return flagged.

**Outputs** (per trajectory): lam1/rJ for rec, pol and noise; lam1_cl; div_*; ret, ret_terms, ret_unc, n_term, ret_diverged; seconds.
