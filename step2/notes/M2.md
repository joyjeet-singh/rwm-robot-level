# M2: fidelity measures and calibration code (2026-11-07)

**Built.**
- `scripts/s2/fidelity.py`:
  - (a) replays recorded joint commands from recorded states, with evalh's windows (E1, E8, E24, E100), the torque error in N·m and per-group errors;
  - (b) runs the authors' policy on the protocol (10 schedules × 8 seeded starts): falls, two-feet share, duty, speed and turn errors, physics return;
  - (c) gives the recorded data's gait statistics on the same schedules.
- `scripts/s2/calibrate.py`: the fixed 108-point grid; objective E8 on the training arena (16 trajectories), ties by E1. It is resumable, with one file per point in `results/s2/calib/`. It refuses episodes 1 and 8. `--freeze` writes `step2/model/calibration.json` and `anymal_d_cal.xml`, both read-only.
- `step2/jobs/calib.zsh`: tests, then the grid (4 workers), freeze, (a) uncalibrated and calibrated on held-out, (b), (c), report.

**Tests** (`results/s2/m2_tests.json`, all pass, about 7 s):
- A placed start reproduces the recorded state to 3.5e-7, and its lowest foot is at 0 m.
- A 100-step replay is finite and stable.
- Window starts and visited windows equal evalh's. The hold-last error equals `evalh.window_floor` to 1.3e-7.
- Held-out episodes are refused by the function, the command line, and the replay before freezing.

**Found.** Setting armature at run time leaves MuJoCo's compile-time quantities stale, and these change contact softness. So each grid point is compiled from its own model text (DECISIONS.md M2).

**Cost.** One grid point takes about 8.5 s, single thread. The whole job should take about 15–25 minutes.

**Scope.** Fidelity is measured against a hand-built model, not the data's simulator or hardware. Nothing in this session measured walking or a held-out episode. The 50-step policy smoke test checked only that values are finite.

**For M3.** Gate 1 reads `results/s2_fidelity.json` → `gait_authors_policy.calibrated.summary` against `gait_recorded.summary`. Reuse `run_policy_episode`, `eval_start` and `schedule` for policy evaluation, with `make_env("cal", reward=True)`.
