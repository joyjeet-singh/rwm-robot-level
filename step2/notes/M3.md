# M3: Gate 1 and the pilot job (2026-11-08)

**Gate 1: passed.** The authors' policy in the calibrated model (friction 0.6, time constant 0.01 s, armature 0.02, damping 0), 80 episodes, against the recorded data on the same ten schedules (`results/s2_fidelity.json`):
- **G1** falls: 1 of 80 episodes (1.25%) < 10%. Pass.
- **G2** two feet down: 0.789 against 0.844 recorded; gap 5.5 points ≤ 10. Pass.
- **G3** speed-tracking error: 0.069 m/s against 0.072 m/s recorded; ratio 0.95 ≤ 1.5. Pass.

Not gated, stated plainly: turn error is 0.061 rad/s against 0.138 recorded. The recorded velocity command is a reconstruction (Step 0 regime means), so this comparison is loose. The uncalibrated model also passed all three. This is a hand-built model, not the data's simulator or hardware.

**Built.**
- `scripts/s2/train_policy.py`: wraps `run_lite.py` (500 iterations, 4,096 robots, seed, holdout from the fold). For compressed copies it applies the variant itself, because `run_lite` ignores variants and would load the parent. It checks the parent hash and the variant's counts against `models.json`, and asserts that the lite trainer took that simulator. It exports the actor to `runs/s2/<policy>/actor.pt` and writes `results/s2/train/<policy>.json` with the imagined return.
- `scripts/s2/evaluate.py`: M2's protocol unchanged; return and fall rate with 95% bootstrap intervals; resumable; refuses non-pilot policies until `PREREG_S2.md` is committed.
- `scripts/s2/pilot_report.py`; `step2/jobs/pilot.zsh` (tests, two training workers × 2 threads, four evaluations, report). `zsh -n` passes; the report was dry-run on test outputs.

**Tests** (`scripts/s2/test_m3.py`, about 35 s, all pass): export equals the last checkpoint; the 50%-pruned simulator has exactly 705,472 zero weights; released route without holdout; one episode measured, equal to M2's function, rerun skipped; guards hold. `results/s2/m3_tests.json` is from the first passing run; a rerun after adding the "simulator taken" assertion also passed (`.cache/s2_m3_tests_rerun.json`).

**For M4.** Gate 2 reads `results/s2_pilot.json`. Main job: `train_policy.py --sim <key> --seed <s>`, then `evaluate.py --policy <key>__p<s>`.
